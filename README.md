### ✨ Features

* 📖 **Book Catalog Grid:** Display available titles with cover art, authors, prices, and ratings.
* 🔍 **Search & Category Filters:** Filter books by genre, author, or search term.
* 🛒 **Shopping Cart & Hover UI:** Interactive product cards with dynamic add-to-cart state and hover effects.
* 📱 **Fully Responsive:** Styled layout optimized across desktop, tablet, and mobile browsers.
